# Dark Myth Kingdom

Dark Myth Kingdom is a Minecraft plugin designed to create a vast ancient Chinese fantasy kingdom with enormous mountains, misty valleys, dangerous cliffs, waterfalls, rivers, caves, forests, ruined villages, temples, palaces, and hidden paths. It includes a giant mountain temple, a dark kingdom palace, custom bosses and enemies inspired by Chinese mythology, and player powers and weapons. The plugin is compatible with Minecraft Android Bedrock Edition / Pocket Edition, specifically targeting version v26.52, build 51798909.

## Install

1. Download the plugin JAR file from the GitHub releases page.
2. Place the JAR file in the `plugins` folder of your Minecraft server or Bedrock Edition world.
3. Start or restart your Minecraft server or Bedrock Edition world.

## Use

1. Once the plugin is installed, join your Minecraft world.
2. Use the `/ciao` command to greet the player and verify the plugin is working.
3. Explore the generated world to discover the ancient Chinese fantasy kingdom, including the giant mountain temple, dark kingdom palace, and hidden paths.
4. Fight custom bosses and enemies inspired by Chinese mythology.
5. Use the magical staff inspired by the legendary Ruyi Jingu Bang to gain powers and weapons.
